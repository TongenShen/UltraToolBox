## 五、视图功能说明

### 5.1 Home.vue — 首页
- 工具卡片入口展示

### 5.2 AdbView.vue — ADB 工具
- 标签页: 设备管理 / 快捷操作 / APK 管理 / Logcat / 文件浏览
- 功能: 设备列表扫描、Wi-Fi 连接、截图/录屏/重启/设备信息、APK 安装/卸载/列表搜索、Logcat 实时日志、文件浏览/拉取

### 5.3 NetworkView.vue — 网络工具
- 标签页: Ping / iPerf3 / cURL
- Ping: 目标地址、发送次数
- iPerf3: 客户端模式 (服务器/端口/时长/反向) / 服务器模式
- cURL: 请求方法/URL/请求头/请求体/超时时间
- 输入框均带 TooltipInput 悬浮提示

### 5.4 Aria2View.vue — Aria2 下载
- 标签页: HTTP 下载 / BT 磁力 / 服务器管理
- HTTP: URL 下载、下载目录、任务列表
- BT: 磁力链接、种子文件
- 服务器: RPC 端口/Secret/并发数/速度限制
- 输入框均带 TooltipInput 悬浮提示

### 5.5 TerminalView.vue — 终端
- 内置终端模拟器

### 5.6 Settings.vue — 设置
- 标签页: 通用 / 二进制工具
- 通用: 主题切换 (深色/浅色)、语言切换 (zh-CN/en-US/ja-JP/ko-KR)、应用信息
- 二进制: 检测已安装的工具 (ADB/iPerf3/Aria2/curl/ping) 及版本

### 5.7 About.vue — 关于
- 应用版本、定位、技术栈、平台信息

## 七、Shell 命令安全

### 权限声明 (`capabilities/default.json`)
已授权的 shell 命令 (execute + spawn):

| 命令 | 用途 |
|------|------|
| `sh` | 通用 shell 执行 |
| `ping` | 网络连通性测试 |
| `adb` | Android 调试桥 |
| `iperf3` | 网络带宽测试 |
| `aria2c` | 多协议下载 |
| `curl` | HTTP 请求 |
| `pkill` | 终止进程 |

### 命令执行模式
- **executeCommand**: 执行并等待返回结果 (一次性)
- **spawnCommand**: 实时输出流 (带 kill 回调)
- **executeSidecar**: 执行内置 sidecar 二进制

## 八、状态管理

### 8.1 appStore (全局设置)
| 状态 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| theme | `'dark' \| 'light'` | `'dark'` | 主题模式 |
| locale | `'zh-CN' \| 'en-US' \| 'ja-JP' \| 'ko-KR'` | `'zh-CN'` | 语言 |
| sidebarCollapsed | `boolean` | `false` | 侧边栏折叠 |
| isDark | `computed` | — | 是否为深色主题 |

所有设置持久化到 `localStorage`，key 前缀为 `ultratoolbox-`。

### 8.2 processStore (进程管理)
| 状态 | 类型 | 说明 |
|------|------|------|
| processes | `Map<string, RunningProcess>` | 所有进程 |
| maxLogLines | `number` (1000) | 最大日志行数 |
| runningProcesses | `computed` | 运行中的进程列表 |
| completedProcesses | `computed` | 已完成的进程列表 |

### 8.3 toolsStore (工具二进制)
| 状态 | 类型 | 说明 |
|------|------|------|
| binaries | `ToolBinary[]` | 已检测到的工具列表 |

## 九、国际化

支持 4 种语言，通过 `vue-i18n` (legacy: false) 实现：

| 语言 | 文件 | 回退 |
|------|------|------|
| 简体中文 | `zh-CN.ts` | 默认 |
| English | `en-US.ts` | → zh-CN |
| 日本語 | `ja-JP.ts` | → zh-CN |
| 한국어 | `ko-KR.ts` | → zh-CN |

语言选择持久化到 `localStorage` (key: `ultratoolbox-locale`)。

## 十、版本管理

- **统一来源**: `package.json` 中的 `version` 字段
- **注入方式**: Vite `define` 编译时注入 `__APP_VERSION__`
- **引用文件**: `src/config/app.ts` 导出 `APP_VERSION`
- **使用页面**: App.vue (状态栏)、About.vue、Settings.vue

## 十一、UI 组件规范

### 通用组件
- **LogPanel.vue**: 日志展示面板，支持状态指示 (idle/running/completed/error/killed)、自动滚动、行号、时间戳
- **TooltipInput.vue**: 输入框包装组件，添加 ⓘ 图标悬浮提示，弹窗宽度 140px~420px

### 布局组件
- **AppSidebar.vue**: 侧边栏导航，可折叠 (240px/60px)，顶部主菜单 + 底部设置/关于入口

### 页面通用样式
- 页面容器: `.tool-page` (overflow-y: auto) + `.tool-container` (max-width: 800px, 居中)
- 面板: `.panel-section` (卡片背景、圆角边框)
- 标签页: `.tab-bar` + `.tab-btn`
- 表单: `.form-row` + `.input` + `.textarea` + `.btn`
- 按钮: `.btn` (默认) / `.btn-primary` (accent) / `.btn-danger` (error) / `.btn-sm` (小尺寸)
